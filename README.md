# V Pilot Premium Enterprise JSX Website

This release uses React, Vite and `HashRouter`. Hash-based routing fixes GitHub Pages blank screens because navigation remains inside `index.html` and does not require server-side route rewrites.

## Main pages
- Home and Why V Pilot
- Frameworks: ProdSecOps and ProdSecApps
- Solutions: PUDICA 5D Intelligence and ART Pilot
- Services: consulting, managed operations, offensive security, GRC, resilience and forensics
- 5Pilot Ops
- Contact and DevSecOps Engineer careers

## GitHub.com deployment
Upload all files and folders to the repository root. If `.github` is hidden, create `.github/workflows/static.yml` with GitHub's Create new file option. In Settings > Pages, select GitHub Actions.
